# 01-01-15 - Registro de definiciones de MVP01

## Función del documento

Este es el único documento que se actualiza durante las encuestas de definición de MVP01.

Al terminar las encuestas se utilizará para actualizar:

- El resumen humano.
- El contexto completo para IA.
- El modelo de datos.
- La lista final de tareas.
- Los demás documentos afectados.

## Alcance vigente de MVP01

- Primera pantalla de pedidos activos y sus líneas.
- Datos de pedidos, clientes, artículos, vendedores y stock provenientes de ISIS.
- Facturas, remitos y recibos relacionados provenientes de ISIS.
- Taller y Entrega administrados manualmente en GestionCyE.
- El pedido permanece activo mientras tenga alguna acción pendiente: entrega, fabricación, remisión, facturación o pago.
- Al terminar, el pedido sale de la lista activa y conserva su historial.
- Para remitos y facturas se debe comparar la cantidad del pedido con las cantidades relacionadas. Una factura deja de mostrar `Falta pago` cuando los recibos aplicados cubren su importe y no queda saldo pendiente.

## Método de trabajo

- Una pregunta por vez.
- Cada pregunta tiene un código único relacionado con su tema.
- La respuesta vigente se registra inmediatamente en este archivo.
- Una decisión anterior puede corregirse.
- Una corrección no borra el antecedente: se registra en el historial de cambios.
- No se incorporan decisiones de módulos posteriores a MVP01.
- Ningún supuesto técnico se registra como decisión del usuario.
