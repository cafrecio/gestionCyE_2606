# Sistema ISIS y alcance del proyecto

## Sistema ERP actual

La empresa trabaja actualmente con un ERP llamado **Sistema ISIS**.

ISIS es el sistema principal de gestion de la empresa. Segun el uso actual, cubre gran parte de las necesidades operativas y administrativas, pero presenta algunas limitaciones importantes:

- Es un sistema viejo.
- Los formularios no son comodos.
- Algunas tareas necesarias para la operatoria diaria no estan incluidas.
- Algunas gestiones podrian resolverse con pantallas o flujos mas simples y adaptados a la forma real de trabajo de la empresa.

## Alcance del nuevo sistema

El nuevo sistema no busca reemplazar a ISIS en esta etapa.

El objetivo inicial es construir un sistema complementario que:

- Tome informacion base desde ISIS.
- Agregue tareas, controles o flujos que ISIS no tiene incluidos.
- Mejore la comodidad de uso en procesos puntuales.
- Ayude a ordenar la gestion diaria entre administracion, ventas y taller.

## Relacion entre ISIS y el nuevo sistema

ISIS seguira siendo la fuente principal de informacion base.

El nuevo sistema debera apoyarse en esa informacion para evitar duplicar carga de datos innecesariamente. En futuras etapas se debera definir con precision:

1. Que datos se toman desde ISIS.
2. Como se accede a esos datos.
3. Con que frecuencia se actualizan.
4. Que datos se pueden modificar desde el nuevo sistema.
5. Que datos deben seguir modificandose solamente en ISIS.
6. Que informacion propia generara el nuevo sistema.

## Criterio inicial

La regla de trabajo inicial es:

> ISIS es el sistema base. El nuevo sistema lo complementa.
